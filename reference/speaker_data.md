# Speaker Data

Speaker Data

## Usage

``` r
speaker_data
```

## Format

### `speaker_data`

A data frame with 10,697 rows and 8 columns

- speaker:

  Speaker ID column

- vowel:

  CMU Dictionary vowel class

- plt_vclass:

  Modified Labov-Trager vowel class

- ipa_vclas:

  IPA-like vowel class

- word:

  Word that the vowel appeared in

- F1, F2, F3:

  The first, second and third formants, in Hz
